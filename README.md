# PDF Divider

PDF sayfalarını seçip çıkarmak veya belgeyi bölmek için ücretsiz web uygulaması. PDF dosyaları tarayıcıda işlenir; uygulama sunucusuna yüklenmez veya orada saklanmaz.

Canlı uygulama: [pdfdivider.netlify.app](https://pdfdivider.netlify.app/)

## Yerel geliştirme

```bash
npm ci
npm run dev
```

`npm run build` tür kontrolünü ve production build'i çalıştırır; `npm run preview` build çıktısını yerelde sunar. Büyük dosyalardaki performans tarayıcıya ve cihaza bağlıdır.

Ürün kapsamı ve yayın ayrıntıları için [brief.md](brief.md) ve [hosting.md](hosting.md) dosyalarına bakın.
