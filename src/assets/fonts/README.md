# Roboto font assets

Source: [Roboto by Google Android Design on Dafont](https://www.dafont.com/roboto.font). Archive: https://dl.dafont.com/dl/?f=roboto (retrieved 2026-09-30).

Only upright Roboto Regular 400, Medium 500 and Bold 700 are distributed. The archive TTF files (Version 1.00000; 2011, Font data copyright Google 2011) were converted to WOFF2 with FontTools, preserving their glyph set. Turkish letters are included. Thin and italic files are not included.

The archive permission text is preserved verbatim in [NOTICE.txt](NOTICE.txt). No license from a different Roboto release has been substituted. Fonts are served from the app build, with no font CDN request.
